# حاسبة الترقية بالاختيار – UNTM FNFE الحوز

## النشر
ارفع محتويات هذا المجلد كما هي إلى استضافة HTTPS، واجعل `index.html` هو الصفحة الرئيسية.

بعد أول فتح مع الإنترنت، سيُخزَّن التطبيق محليًا ويستطيع المستخدم فتحه لاحقًا بدون إنترنت.

## ملاحظة
زر «مشاركة التطبيق» يستخدم رابط الصفحة الحالية تلقائيًا، لذلك لا تحتاج إلى تعديل الرابط داخل الكود عند تغيير النطاق.
